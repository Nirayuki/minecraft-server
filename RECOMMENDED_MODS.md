# Recommended Mods for Minecraft 1.16.5 Forge Server

This document lists popular and well-tested mods that work great with Forge 1.16.5 (36.2.42).

## 🎯 Essential/Quality of Life Mods

### JEI (Just Enough Items)
- **What it does**: Recipe viewer and item list
- **Why you need it**: Essential for seeing crafting recipes for modded items
- **Download**: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/jei)
- **Server required**: Optional (client-only works, but better on both)

### JourneyMap
- **What it does**: Real-time mapping as you explore
- **Why you need it**: Great for navigation and exploration
- **Download**: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/journeymap)
- **Server required**: Optional (works client-only)

### Quark
- **What it does**: Many small vanilla-style improvements
- **Why you need it**: Adds useful features without being overwhelming
- **Download**: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/quark)
- **Server required**: Yes
- **Dependencies**: AutoRegLib

### AutoRegLib
- **What it does**: Library mod (required by Quark and others)
- **Why you need it**: Dependency for several mods
- **Download**: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/autoreglib)
- **Server required**: Yes (if using mods that require it)

## 🌍 World Generation & Biomes

### Biomes O' Plenty
- **What it does**: Adds 80+ new biomes
- **Why you need it**: Beautiful and diverse landscapes
- **Download**: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/biomes-o-plenty)
- **Server required**: Yes
- **Note**: Select "BIOMESOP" world type when creating world

### Oh The Biomes You'll Go
- **What it does**: Alternative biome mod with unique biomes
- **Why you need it**: Different style than Biomes O' Plenty
- **Download**: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/oh-the-biomes-youll-go)
- **Server required**: Yes
- **Note**: Don't use with Biomes O' Plenty (choose one)

## ⚙️ Technology & Automation

### Applied Energistics 2 (AE2)
- **What it does**: Digital storage and autocrafting
- **Why you need it**: Best storage system in modded Minecraft
- **Download**: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/applied-energistics-2)
- **Server required**: Yes

### Mekanism
- **What it does**: Tech mod with ore processing, power generation
- **Why you need it**: Powerful and well-balanced tech progression
- **Download**: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/mekanism)
- **Server required**: Yes
- **Add-ons**: Mekanism Generators, Mekanism Tools

### Thermal Expansion
- **What it does**: Machines, power systems, and automation
- **Why you need it**: Classic tech mod, very stable
- **Download**: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/thermal-expansion)
- **Server required**: Yes
- **Note**: Part of Thermal Series (Foundation, Innovation, Cultivation, etc.)

### Refined Storage
- **What it does**: Digital storage system (simpler than AE2)
- **Why you need it**: Easier to learn than AE2
- **Download**: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/refined-storage)
- **Server required**: Yes
- **Note**: Alternative to AE2, choose based on preference

## ⚠️ Important Notes

### Installing Mods:

1. **Download the correct version**: Must be for Minecraft 1.16.5 and Forge
2. **Check dependencies**: Some mods require library mods
3. **Install on both sides**: Most mods need to be on both server and client
4. **Test compatibility**: Add mods gradually to identify conflicts

### Mod Compatibility:

- Some mods don't work well together
- Always backup your world before adding new mods
- Check mod pages for known incompatibilities
- Start with fewer mods and add more gradually

### Performance Tips:

- More mods = more RAM needed
- Tech mods can be resource-intensive
- World generation mods increase load times
- Consider increasing RAM allocation to 4GB+ for many mods

### Where to Download:

**Trusted sources only:**
- ✅ [CurseForge](https://www.curseforge.com/minecraft/mc-mods)
- ✅ [Modrinth](https://modrinth.com/mods)
- ✅ Mod developer's official page
- ❌ Random websites (may contain malware!)
